Изменения в КИМ ОГЭ-2027
Изменения в КИМ ОГЭ-2027 по истории
Из работы исключили одно задание повышенного уровня сложности.
Общее количество заданий уменьшилось с 24-х до 23-х.
Максимальный первичный балл уменьшился с 37-ми до 35-ти.
В демонстрационный вариант КИМ ОГЭ добавили приложение с параграфами из учебников, в которых содержится учебный материал для каждого задания.
Изменения в КИМ ОГЭ-2027 по обществознанию
Общее количество заданий сократили с 24-х до 20-ти.
Максимальный первичный балл сократили с 37-ми до 32-х.
Изменился порядок следования ряда заданий.
В демонстрационный вариант КИМ ОГЭ добавили приложение с параграфами из учебника с материалами для каждого задания.
Изменения в КИМ ОГЭ-2027 по русскому языку
Отдельные уточнения коснулись сочинения-рассуждения на основе опорного текста. В формулировки и систему оценивания этих заданий внесли обязательное требование – пояснение приводимых примеров из прочитанного текста.
Увеличили максимальное количество баллов за всю работу с 37-ми до 38-ми.
Изменения в итоговом собеседовании 2027
Общее количество заданий итогового собеседования сократили с 4-х до 3-х. Исключили подробный пересказ текста. При этом формы выборочного пересказа текста сохранили в новом задании под номером 2. Теперь в задании 2 не будет диалога на жизненные темы, оно будет представлено в формате беседы по прочитанному тексту. Количество вопросов для диалога увеличили с 3-х до 5-ти. Максимальный балл за выполнение нового задания – 5.
Максимальный первичный балл за всю работу уменьшили с 20-ти до 17-ти баллов.
Изменили процедуру проведения итогового собеседования. А именно – увеличили время на подготовительную работу с текстом с 2-х до 5-ти минут. На подготовку монологического высказывания – с 1-й до 2-х минут. При этом общее расчетное время на проведение итогового собеседования для одного школьника сохраняется – 15–16 минут.
